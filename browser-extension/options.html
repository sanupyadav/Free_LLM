Freebuff2API Extension Settings

Gateway port. Leave blank to auto-probe the default sequence: 47821 -> 47822 -> 8787.

Priority: port supplied by the gateway panel > port set here > default list. The panel's "One-click login" automatically passes its own port, so this usually doesn't need to be filled in.

Gateway API key (optional). Leave blank if the gateway has no api_keys configured; if the panel reports a 401 (the gateway has API key validation enabled), paste the key shown on the panel here.

Compatible with older gateways: when left blank, no Authorization header is sent, and local direct connections still work.

To verify it took effect: click "🔑 One-click login" on the gateway panel, or click the extension icon directly — the notification will show the result and the port used.
